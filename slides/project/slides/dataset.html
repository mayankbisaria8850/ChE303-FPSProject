ZestLoop · CSV dataset and website

How the Aspen results were exported: Sensitivity S-1 varied feed (through the liquid flow, with the SCALE-FD calculator scaling solids) and screen cut size, tabulating four outputs; 42 converged cases. How it is organised: the website reads the raw CSV unchanged, cleans the headers, converts units and checks the grid. How results are retrieved: exact lookup when the inputs hit a simulated case, otherwise 2-D interpolation. Along feed every output is exactly linear; along cut size the curves bend, so we use PCHIP, a monotone cubic. We tested it blind on the base case, which is in the Aspen report but not in the CSV: PCHIP is within 0.003 percent, linear is 0.31 percent off. The website is Streamlit in Python and needs no Aspen connection.
